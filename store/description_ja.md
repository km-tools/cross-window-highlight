# ストア説明文（日本語）

Chrome ウェブストアの説明欄はプレーンテキストです。見出し記号や太字は使えないので、下の「本文」は改行と記号だけで組んでいます。

## 名前

クロスウィンドウ・ハイライト

## キャッチ（ストアの「概要」欄、132文字以内）

二画面照合を、選択するだけで。片方の画面で文字を選ぶと、別のタブやウィンドウの一致箇所が光ります。転記・突合を人が確認する作業を支援します。

## 本文

【こんな人のために】
チャットや PDF の注文メモを見ながら受注システムに入力する。請求書と伝票を見比べる。名簿と申込フォームを突き合わせる。
そんな「2つの画面を行き来して、目で照合・転記する」事務・経理・受注処理・データ入力の作業のための拡張機能です。

【困りごと】
右の画面の氏名や番号が、左の画面と本当に同じか。目で追うと見落とすし、コピーして検索するのは手間がかかります。

【この拡張がすること】
片方の画面で文字を選択するだけで、開いている他のタブやウィンドウの一致箇所がその場で光ります。
・選択するだけ。コピーも検索窓も要りません
・別ウィンドウでも、別タブでも光ります
・入力欄（フォーム）の中身が一致していれば、その欄に枠が付きます
・選択を外すと自動で消えます。Esc でそのページだけ消すこともできます
・ON / OFF はツールバーのアイコンをクリックして表示されるスイッチ、またはショートカット Ctrl+Shift+H（Mac は Cmd+Shift+H）

この拡張は「人による確認を支援する」道具です。自動で判定したり、入力を書き換えたりはしません。

【光った＝正しい、ではありません】
見落としを減らすため、空白・ハイフン・全角半角・大文字小文字の違いは無視して一致を探します。そのため、光った箇所が選択した文字と完全に同じとは限りません。
・黄色：完全一致（1文字残らず同じ）
・薄い橙 + 点線：表記違いの一致（上の違いを無視して同じ）。マウスを乗せると説明が出ます
一致が 1 件もないときは「一致なし」と表示し、拡張が動作しないページ（ブラウザの設定画面、PDF ビューアなど）があれば「確認できなかったタブ」として別に知らせます。ポップアップで「完全 n / 表記違い m」の内訳も確認できます。

【無料でできること】
・タブ／ウィンドウ間のハイライト
・完全一致と表記違いの色分け
・「一致なし」と「確認できない」の区別
・ショートカットでの ON / OFF、Esc での解除

【Pro でできること（ライセンスキーで解放）】
・ハイライトの色を変える（完全一致・表記違い・入力欄の枠）
・厳密比較モード：表記の違いを無視せず、完全一致だけを探す
・最小文字数の変更（1〜10 文字）
・除外ドメイン：特定のサイトでは動かさない
・ヒット件数をアイコンに表示
・改行・読点・カンマで区切った複数の語を同時にハイライト
・iframe の中もハイライト

【プライバシー】
選択した文字列は、お使いの端末内のタブ間でしか受け渡しません。閲覧履歴・ページ内容・選択文字列を外部に送ることはなく、アクセス解析も入っていません。
外部との通信は、Pro 版のライセンスキー確認（キー文字列のみを送信）だけです。
プライバシーポリシー: https://km-tools.github.io/cross-window-highlight/privacy.html

【動作しないページ】
Chrome の設定画面（chrome://）、Chrome ウェブストア、他の拡張機能のページ、PDF ビューアでは動作しません。これらは「確認できなかったタブ」として表示されます。
