# Store listing (English)

The Chrome Web Store description field is plain text. No headings or bold, so the body below uses line breaks and simple markers only.

## Name

Cross-Window Highlight

## Summary (store "summary" field, 132 characters max)

Select text in one window and matching text lights up in your other tabs and windows. Helps you check side-by-side data entry by eye.

## Description

WHO IT IS FOR
Typing an order from a chat or a PDF into an order system. Comparing an invoice with a receipt. Checking a sign-up form against a roster.
This extension is for admin, accounting, order-processing and data-entry work where you move between two screens and check or copy values by eye.

THE PROBLEM
Is the name or number on the right screen really the same as on the left? Reading it twice is easy to get wrong, and copy-and-search takes time.

WHAT IT DOES
Select text in one window, and every match in your other open tabs and windows lights up right away.
- Just select. No copying, no search box
- Works across separate windows as well as tabs
- If a form field contains the same value, that field gets an outline
- Clearing the selection removes the highlights. Esc clears the current page only
- Toggle ON / OFF with the switch in the toolbar icon's popup, or with Ctrl+Shift+H (Cmd+Shift+H on Mac)

This is a tool that supports checking by a person. It does not judge or change anything for you.

A HIGHLIGHT IS NOT PROOF
To reduce misses, matching ignores differences in spaces, hyphens, full-width vs half-width characters, and letter case. So a highlighted match is not guaranteed to be identical to your selection.
- Yellow: exact match, character for character
- Light orange with a dotted underline: match that differs in formatting. Hover to see why
When nothing matches, the popup says so. Pages where the extension cannot run (browser settings pages, the PDF viewer, and so on) are listed separately as "tabs not checked", so an empty result is never mistaken for a confirmed no-match. The popup also shows the breakdown, e.g. "Exact 2 / Formatting differs 1".

FREE
- Highlighting across tabs and windows
- Different colors for exact and formatting-different matches
- "No match" kept separate from "could not check"
- Keyboard toggle and Esc

PRO (unlocked with a license key)
- Custom colors (exact, formatting-different, input outline)
- Strict comparison: do not ignore formatting, exact matches only
- Minimum length (1 to 10 characters)
- Excluded domains
- Match count on the toolbar icon
- Highlight several words at once, split by newline or comma
- Highlight inside iframes

PRIVACY
Selected text is passed only between the tabs on your own device. Browsing history, page content and selected text are never sent anywhere, and there is no analytics.
The only network request is the Pro license check, which sends the license key string alone.
Privacy policy: https://km-tools.github.io/cross-window-highlight/privacy.html

WHERE IT DOES NOT RUN
Chrome settings pages (chrome://), the Chrome Web Store, other extensions' pages and the PDF viewer. These show up as "tabs not checked".
